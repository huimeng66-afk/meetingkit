# 天穹会议 · iOS 视觉与交互规范

来源：`1235.zip` 网页端（`index.html`，7040 行）的实机渲染与 CSS 令牌。本文是 iOS 原生实现的唯一设计依据，任何视图不得自行发明颜色与圆角。

## 0. 对网页版做的三个修正（"优化"的具体含义）

| 网页版问题 | iOS 版处理 |
|---|---|
| 首页/登录是钉钉浅色克隆（`#fff`、`#1d2028`），会议室是深空蓝（`#04060d`），两套语言割裂 | **统一为深空蓝**。首页、入会页、会议室共用一套暗色令牌，品牌感连续 |
| 桌面 CSS 直接跑在 390pt 宽的手机上，横向溢出（加入按钮被裁、输入框出屏） | 全部改为 SwiftUI 自适应布局，最小支持 iPhone SE 375×667，横向不滚动 |
| 会议室空态是一整块浅灰，没有"等待入会"的信息层级 | 空态给品牌光晕 + 会议号 + "等待参会人加入"，不再是一块死灰 |

## 1. 色彩

| 语义 | 值 | 用途 |
|---|---|---|
| `bg` | `#04060D` | 页面底 |
| `bgElevated` | `#0A1020` | 面板、卡片的不透明底 |
| `card` | `#0F1628` @ 72% | 玻璃卡片底（叠在模糊上） |
| `stroke` | `#5A8CFF` @ 16% | 所有卡片/控件描边；选中态 32% |
| `ink` | `#EAF1FF` | 一级文字 |
| `ink2` | `#9DB0D4` | 二级文字 |
| `ink3` | `#5D6F95` | 三级文字（会议号、时间戳）；不得再低 |
| `accent` | `#4F8CFF` | 主操作、选中、发言高亮 |
| `accent2` | `#22D3EE` | 辅助高亮（加入会议、共享角标） |
| `violet` | `#7C3AED` | 渐变第二色、联席主持人 |
| `ok` | `#22C55E` | 共享中、连接正常 |
| `warn` | `#F59E0B` | 重连、弱网 |
| `danger` | `#EF4444` | 麦克风/摄像头关闭、结束会议、共享警示条 |

品牌渐变：`#3B82F6 → #7C3AED`（135°）。页面背景叠三层径向光晕：左上蓝 20%、右上紫 17%、底部青 11%，透明度极低，只做"星空感"，不能影响文字对比度。

## 2. 形状与间距

- 卡片 16、瓦片 14、小窗 12、面板顶部 28、主按钮 14、胶囊 999
- 间距 4 的倍数；页面水平边距 20（比网页的 18 更接近 iOS 习惯）
- 触控目标 ≥ 44×44；底栏按钮视觉 48，命中区 56
- 玻璃：`UIVisualEffectView(.systemUltraThinMaterialDark)` + `card` 底 + 1px 上亮下暗渐变描边 + 阴影 `black 0.35 / 18 / y8`
- iOS 26：原生 `glassEffect`，与降级版共用同一套 variant

## 3. 屏幕

### 3.1 入会页（PreJoin）
- 顶部品牌：44 圆角方块 logo（渐变 + 摄像机图形）+ "天穹会议"
- 预览区：16:10，圆角 20，渐变底 + 大头像 + 姓名；右下角麦克风/摄像头两个玻璃胶囊（关闭时红底斜杠）
- 表单：会议号（数字键盘、7 位 3+4 分组显示）、你的名称
- 主按钮：渐变蓝紫，高 52；会议号为空时禁用
- 副链接："发起新会议"（生成会议号并填入）

### 3.2 首页（Home）
- 顶部：头像 38 + 昵称；右侧搜索、通知（红点）
- 标题 "天穹会议" 28 bold + 副标题 "高效稳定的企业级视频会议"
- 双卡：发起会议（蓝紫渐变图标）/ 加入会议（青绿渐变图标），各占一半，高 132
- 历史会议：卡片列表，每行标题 + 时间 + 会议号，点击直接进预入会；长按删除
- 底部 Tab：会议 / 联系人（联系人页先做通讯录空态 + 邀请，不造假数据）
- 背景三层光晕

### 3.3 会议室（Room）
**顶栏**（高 52 + 安全区）
- 左：收起（最小化）、扬声器/听筒、视图切换，三个 36×36 图标
- 中：会议标题 14.5 semibold；下方时长 11 `ink2`；再下方会议号（超窄屏隐藏）
- 右：橙色 `#F0510F` 圆角胶囊"结束"（仅主持人），文字 13
- 背景玻璃；共享时顶栏下方 32pt 红色通栏警示条（含时长 + 停止共享）

**画布**
- 共享态：黑底 + `.scaledToFit`（绝不裁切）+ 左上"正在共享"玻璃角标 + 右上"收起"
- 演讲者：主画面 `.scaledToFill` + 顶部渐变遮罩；顶部缩略图条 104×96 圆角 10，选中描边 2pt `#007FFF`
- 宫格：≤4 人 2 列，5–9 人 3 列，>9 分页；瓦片 14 圆角、间距 6；说话者 2pt 蓝边 + 外发光；共享者左上绿色"共享中"角标
- 空态：品牌光晕 + "等待参会人加入" + 会议号 + 复制邀请按钮
- 左下浮动：表情/聊天二合一玻璃胶囊 + 自己名字牌；右下：画中画按钮（切宫格）

**底栏**（7 键，等宽，高 64 + 安全区）
静音 / 摄像头 / 安全 / 邀请 / 成员(带人数) / 共享 / 更多
- 关闭态：红底 `danger 16%` + 红字 + 斜杠图标；开启：白 6% 玻璃
- 共享中：红底实心 + 白字 + 光晕
- 标签 10pt，`ink2`；激活时 `ink`

**面板**（自绘 GlassSheet，三档：58% / 88%）
- 成员：搜索、主持人/参会人分组、角色角标、静音/举手/弱网状态、底部"全部静音 / 锁定 / 移出"
- 聊天：系统消息、左右气泡、输入区（键盘压缩面板而不是整块上移）
- 共享：共享屏幕 / 白板（即将上线）/ 三步说明 / 主按钮
- 邀请：会议号大字 + 复制链接 + 二维码（CoreImage 生成）+ 分享
- 安全：锁定会议、等候室、入会静音、允许共享（开关）
- 更多：举手/录制/虚拟背景/美颜/降噪/翻转摄像头/设置
- 设置：昵称、头像色、关于

所有面板顶部 36×4 拖拽条 + 28 圆角 + 玻璃。面板打开时画布不变暗超过 45%，保证还能看见会议。

## 4. 动效
统一 `.spring(response: 0.34, dampingFraction: 0.86)`；按钮按下 0.96；面板 0.25 弹簧；说话者光环 1.2s 循环；共享警示条 0.2s 高度展开。禁止满屏 easeInOut。

## 5. 无障碍
- 所有图标按钮 `accessibilityLabel`
- 底栏标签不只靠颜色区分（关闭时同时有斜杠图标 + 文案"取消静音"）
- 支持 Dynamic Type 到 AX1（布局用 `minimumScaleFactor` 兜底）
- 降低透明度开启时玻璃退化为实色 `#0A1020` + 更强描边
